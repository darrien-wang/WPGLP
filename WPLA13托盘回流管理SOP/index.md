## 3. 操作流程

### 3.1 操作流程图
```
收到托盘 → 记录到表格 → 询问仓长需求 → 选择提货仓去库存 → 生成BOL → 发送给仓长 → 仓长确认 → 联系司机
```

**调度员职责范围**: 执行到联系司机为止，后续运输和签收由司机和仓库人员负责。

## 4. 详细操作步骤

### 4.1 托盘接收记录
**操作频率**: 每次从提货仓收到托盘后

**操作步骤**:
1. 打开托盘数量统计表
2. 在对应提货仓列中记录收到的托盘数量
3. 记录接收日期和托盘状态（完好/破损）
4. 保存表格更改

### 4.2 托盘回流需求确认
**操作频率**: 每日执行

**操作步骤**:
1. 确认当月需要归还托盘的目标仓库
2. 联系目标仓库的仓长
3. **询问仓长要返多少托盘**
4. 明确仓长要求的归还数量和时间安排

### 4.3 选择提货仓并去库存
**操作频率**: 每次归还托盘前

**操作步骤**:
1. 打开托盘数量统计表
2. 根据仓长要求的归还数量，选择对应的提货仓
3. 在表格中找到该提货仓的托盘数量记录
4. **在表格中减去相应数量**（去库存操作）
5. 保存表格更改

### 4.4 生成托盘回流BOL
**操作频率**: 每次归还托盘前

**操作步骤**:
1. 打开托盘回流BOL模板
2. 复制模板创建新的BOL文档
3. **修改SHIP TO地址**为对应的目标仓库地址
4. **修改CUSTOMER ORDER INFORMATION**：
   - 日期：填写具体月份（如：2025年1月、2025年2月）
   - 数量：填写仓长要求的归还托盘数量
   - 备注：注明"托盘回流 - [具体月份]"
5. 确定归还周期（单月或双月）
6. 核对BOL信息准确性
7. **发送BOL给仓长**，抄送本仓库相关人员

### 4.5 联系司机
**操作频率**: 仓长确认BOL后

**操作步骤**:
1. 等待目标仓库仓长确认BOL信息
2. 打开提货仓车辆配置表
3. 确认目标仓库的具体地址信息
4. 根据目标仓库地址查找历史记录
5. 找到曾经送过这个路线的司机信息
6. **联系司机**，通知执行托盘回流任务
7. 向司机说明任务详情和要求
8. 提供目标仓库的准确地址
9. 确认司机携带正确的BOL副本

## 5. 关键控制点

### 5.1 质量控制点
- **归还数量必须与仓长要求的数量一致**
- 去库存操作必须准确无误
- BOL模板信息必须准确填写
- SHIP TO地址必须与目标仓库一致
- 必须在仓长确认BOL后才能联系司机

### 5.2 沟通协调点
- 保持与各仓库仓长的良好沟通
- **主动询问仓长要返多少托盘**
- 优先选择有该路线经验的司机
- 与司机确认任务详情和运输要求

## 6. 重要提醒

### 6.1 操作要求
- 每次收到托盘后必须立即记录到表格
- 去库存操作必须在生成BOL之前完成
- 每次归还后必须立即更新表格
- 确保表格数据与实际库存保持一致

### 6.2 调度员职责范围
- **调度员负责执行到联系司机为止**
- 后续的运输执行、托盘签收、异常处理等由司机和仓库人员负责
- 调度员需要跟进整体进度，但不直接参与运输操作
