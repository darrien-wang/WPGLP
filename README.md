## 📝 更新文档

### 更新首页日期

每次部署前，请更新 `index.md` 文件中的日期：

```yaml
---
layout: default
title: "WPGLP 仓库管理系统"
permalink: /
last_updated: 2025-09-30  # 👈 修改这里的日期
---
```

### 部署步骤

1. 修改文档内容
2. 更新 `index.md` 中的 `last_updated` 日期
3. 提交更改:
   ```bash
   git add .
   git commit -m "更新文档 - [描述更改内容]"
   git push origin gh-pages
   ```
